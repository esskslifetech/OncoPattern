# Datasets

Every input the platform reads. Two kinds of file live here and they are not
equivalent — the synthetic fixtures exist to make the detectors assertable, the
retrieved fixtures exist to prove the platform is pointed at the real world.

Both are tracked. They are small (≈150 KB together) and they are what makes a
run reproducible without a network connection.

## Synthetic fixtures

Generated by `tools/gen_datasets.py`. Pure standard library, seeded LCG, so the
output is byte-identical on every machine — which is what lets the certificates
assert exact counts rather than tolerances. Regenerate with:

```bash
python3 tools/gen_datasets.py
```

| File | Size | What it is |
|---|---:|---|
| `clinical.csv` | 271 B | six patients: id, histology, stage, age, tumour volume, treatment, follow-up |
| `expression.csv` | 3.1 KB | 40-gene panel × 12 samples (six normal `N1–N6`, six tumour `T1–T6`), log-scale values with a planted tumour/normal driver block |
| `variants_P001_t0.vcf` | 35 KB | 1,000 valid SNVs over a 50 Mb denominator (GRCh38), `t0` |
| `variants_P001_t1.vcf` | 34 KB | the same patient at `t1`, with progression injected into hotspot density and chromosome distribution |
| `histology.pgm` | 33 KB | 96×96 ASCII PGM (P2) pathology field: nuclei, stroma, a necrosis region, a TIL gradient |
| `pathway.json` | 419 B | weighted organ graph (lung, lymph node, liver, bone, …) used by the metastasis model |

The planted ground truth is what the detector certificates assert against: the
SNV hotspot sits at a known locus with a known variant count, the necrosis
centroid at a known pixel, and the seeded genome puts exactly as many variants
on each chromosome as the sweep expects.

Each VCF also carries three deliberately malformed rows (negative position,
negative quality, an invalid contig). They are there to prove that bad records
are **quarantined with their reason code, not silently dropped**.

## Retrieved fixtures

Pulled from public endpoints by the tools below, then committed. The derived
files are small summaries; the `*_provenance.json` files keep the unmodified
API response beside them, so a claim in the report can be traced to the bytes
that produced it.

| File | Source | What it holds |
|---|---|---|
| `patents.json` | [EPO Linked Open Data](https://data.epo.org/linked-data/query) SPARQL, open, no key | publication counts for a 40-gene panel and 12 IPC classes chosen to correspond to the platform's own simulation models, 2010–2024 |
| `patents_provenance.json` | same | the raw response for the count query, unmodified |
| `papers.json` | [Europe PMC](https://www.ebi.ac.uk/europepmc/) REST, curated index over PubMed/MEDLINE and PMC | title-verified references backing the platform's thresholds and models, with PMIDs, DOIs and citation counts |
| `papers_provenance.json` | same | the raw response for the query that produced the reference set, unmodified |

```bash
python3 tools/fetch_patents.py    # re-pull the patent landscape (~2 min)
python3 tools/fetch_papers.py     # re-pull the evidence base (~2 min)
```

**These numbers drift.** The endpoints are live and the databases keep growing,
so a re-pull today will not reproduce the counts quoted in the README. The
committed files pin the figures that the documents and the certificates refer
to; the `retrieved` field in each JSON records when that was. Do not hand-edit
either file — re-pull, and say in the commit what changed and why.

## Not data

`datasets/` holds inputs only. Everything the platform writes — reports,
journals, framebuffers, `patterns.tfs` — goes to `results/`, which is not
tracked. See `.gitignore`.

## Provenance and licence

- The synthetic fixtures are original to this project, under the repository's
  [Apache License 2.0](../LICENSE).
- Patent metadata is published by the European Patent Office as Linked Open
  Data; what is stored here is aggregate counts derived from it, with the
  response kept for verification.
- Bibliographic metadata is from Europe PMC (EMBL-EBI). Titles, PMIDs, DOIs and
  citation counts are facts about publications, not reproductions of the
  articles; the articles themselves are cited, not redistributed.

No patient data is present, real or derived. The clinical and genomic fixtures
are generated.
